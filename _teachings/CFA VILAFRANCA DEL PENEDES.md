# COMPETIC 3

## Presentación del curso

Este curso culmina la formación recibida en Competic 2. Para aprobar los alumnos han de superar dos de las tres competecias que se imparten:

- Procesador de textos
- Presentaciones
- Hoja de cálculo

## Prerequisitos

- Se trabaja con libreoffice
- Es imprescindible tener aprovado competic 2
- Es imprescindible trabajo personal para poder completar el curso
